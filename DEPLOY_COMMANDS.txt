# ==============================================================================
# GUÍA RÁPIDA DE COMANDOS: LOCAL Y DESPLIEGUE (VERCEL + NEON)
# ==============================================================================

# ------------------------------------------------------------------------------
# 1. EJECUTAR EN LOCAL (WINDOWS POWERSHELL)
# ------------------------------------------------------------------------------
# Instala dependencias y corre Next.js (:3000) y Flask (:5328) en paralelo.
# Utiliza SQLite local (local.db) sin necesidad de configurar base de datos externa.

# Si aún no tienes el entorno virtual creado:
python -m venv .venv
.\.venv\Scripts\pip install -r requirements-dev.txt
npm install

# Correr servicio localmente:
$env:PATH = "$PWD\.venv\Scripts;$env:PATH"
npm run dev

# Correr pruebas automatizadas:
.\.venv\Scripts\pytest


# ------------------------------------------------------------------------------
# 2. SUBIR EL CÓDIGO A GITHUB
# ------------------------------------------------------------------------------
# (Crea un repositorio vacío en github.com y ejecuta en la raíz del proyecto):

git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git branch -M main
git push -u origin main


# ------------------------------------------------------------------------------
# 3. VARIABLES DE ENTORNO REQUERIDAS EN VERCEL
# ------------------------------------------------------------------------------
# En el panel de Vercel (Project Settings -> Environment Variables), añade:
#
# DATABASE_URL = postgresql://neondb_owner:TU_PASSWORD@ep-xyz.us-east-2.aws.neon.tech/neondb?sslmode=require
# SECRET_KEY   = (puedes generar uno ejecutando: python -c "import secrets; print(secrets.token_hex(32))")
# SEED_DEMO_USERS = 1


# ------------------------------------------------------------------------------
# 4. DESPLIEGUE VÍA VERCEL CLI (OPCIONAL, SI PREFIERES TERMINAL)
# ------------------------------------------------------------------------------
# Login en Vercel:
npx vercel login

# Asociar y desplegar en preview:
npx vercel

# Desplegar directamente a producción:
npx vercel --prod
